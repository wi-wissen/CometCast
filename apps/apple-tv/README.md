# Comet Cast - Apple TV receiver (native SwiftUI, tvOS 17+)

> **UNVERIFIED: written without Xcode, a Mac or an Apple TV.** The platform independent part
> (`CometCastCore`) is tested on Linux; the app target has never been compiled. Read
> [docs/appletv.md](../../docs/appletv.md) first and test with
> [docs/appletv-device-test-plan.md](../../docs/appletv-device-test-plan.md).

A **display only** app (License: GPL-3.0-or-later; never a presenter). The Rust core is not used on tvOS: signalling, the content
channel, ALTCHA and the relay rules are implemented in Swift and checked against the web client with shared vectors
(`tests/fixtures`).

## Layout

| Path | What |
| --- | --- |
| `CometCastCore/` | Swift package: protocol messages, content parser and limits, ALTCHA, connection check code, relay and server-list rules, state machines, and the rules of the designed screens (design numbers, wizard, key tables, reconnect schedule, QR code, licence list). No Apple-only imports; `swift test` runs on Linux |
| `Sources/CometCastTV/` | SwiftUI app: `AppModel`, `Design/` (tokens, components), `Services/` (socket, HTTP, WebRTC, discovery, decoders, configuration), `Views/` (setup wizard, idle, Settings, About, join request, presenting, link card) |
| `Sources/CometCastTV/Localizable.xcstrings`, `InfoPlist.xcstrings` | English and German "du" (shipped). `Localizable-sie.xcstrings` is the formal set, not loaded unless `CC_STRINGS_TABLE` says so. Generated by `node tools/gen-appletv-strings.mjs` |
| `Resources/Info.plist` | `NSLocalNetworkUsageDescription`, `NSBonjourServices`, local networking exception, `CCDefaultRelay`, `CCStringsTable`, `UIAppFonts` |
| `Resources/Fonts`, `Resources/Licenses` | Atkinson Hyperlegible files (OFL) and the licence copies that About shows (`node tools/gen-third-party.mjs`) |
| `Assets.xcassets/` | tvOS layered app icon (placeholders from `assets/logo`; see docs/appletv.md), `Icons` and `Logo` (generated by `node tools/gen-appletv-icons.mjs`) |
| `project.yml` | XcodeGen spec (app and unit-test targets, scheme `CometCastTV`, packages) |

## Tests

```sh
cd CometCastCore && swift test        # Linux or macOS; 140 tests, the same fixtures as the web client
```

## Open it on a Mac (Xcode 15+ and Homebrew)

```sh
brew install xcodegen
cd apps/apple-tv
xcodegen generate          # creates CometCastTV.xcodeproj from project.yml
open CometCastTV.xcodeproj
```

In Xcode: select the CometCastTV target, Signing & Capabilities, choose your Team, pick an Apple TV simulator
(or the paired Apple TV) as destination, press Run (Cmd+R). The first build downloads the 686 MB WebRTC package.
Expect to fix compile errors in the app target on the first build and write them down (the test plan, part A,
lists the likely places).

## Settings you may want

- `CC_DEFAULT_RELAY` in `project.yml` (build setting, empty by default): the server used when nothing else is
  configured, the counterpart of the web app's `VITE_DEFAULT_RELAY`. The built-in default `relay.cometcast.de` does
  not exist yet.
- Managed app configuration (MDM): `servers`, `forbid_default_list`, `forbid_user_override`, `forbid_announcement`
  (see docs/appletv.md, "Servers").
