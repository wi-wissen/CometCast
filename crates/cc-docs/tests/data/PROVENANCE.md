# Test PDFs: provenance

All files are **generated by `gen_test_pdfs.py`** in this folder (our own work,
GPL-3.0-or-later). No third-party documents. Generated on 2026-11-06 with Python 3.13,
reportlab 5.0.1 and Pillow 12.3.0. Re-running the script writes the files again; the
hand-written ones come out byte-identical, the reportlab ones use `invariant=1` (no
timestamps, fixed IDs) but the encrypted ones may differ in bytes between runs (UNCERTAIN:
whether reportlab uses random values there was not checked). Expected colours and positions
are asserted in `../render.rs`; the layout numbers below match those tests.

| File | How made | What it is for |
| --- | --- | --- |
| `minimal.pdf` | hand-written (Python bytes, correct xref) | 200 x 100 pt, red left half, blue right half, "Hi" in Helvetica (not embedded) |
| `no_xref.pdf` | `minimal.pdf` cut before the `xref` table and trailer | damaged file: reader must rebuild the table |
| `two_pages_one_rotated.pdf` | hand-written | page 1 yellow 200 x 100; page 2 `/Rotate 90` (displayed 100 x 200), green with a red box |
| `rotated_pages.pdf` | hand-written | four pages, MediaBox 200 x 300, `/Rotate` 0, 90, 180, 270; red box in the unrotated top left corner |
| `slides.pdf` | reportlab | 3 A4 pages: (1) Helvetica-Bold and Times text, green rectangle, yellow circle, Bezier curve; (2) embedded 64 x 32 px JPEG (orange / teal halves, made with Pillow, quality 95) and text; (3) embedded TrueType font (subset of Bitstream Vera, which reportlab ships) and a linear gradient clipped to a rectangle |
| `encrypted_empty_user_password.pdf` | reportlab, RC4 128 bit, user password empty, owner password "owner" | must open and render |
| `encrypted_password.pdf` | reportlab, RC4 128 bit, user password "secret" | must be refused with `PasswordProtected` |

Not covered by files here: AES encryption, CJK text, non-embedded CID fonts, JPEG 2000,
transparency groups, forms, scans, real PDFs. Hostile inputs are built in memory
by the tests (`../hostile.rs`, `../limits.rs`, `../sandbox.rs`, `../poison.rs`), not stored.

## Review generators

`review_gen.py` and `review_gen2.py` are the hostile-PDF generators of the independent review of
this crate (2026-11-06), copied unchanged below a provenance header (own work of the review,
GPL-3.0-or-later like the repository). They are documentation of the shapes the review used
and are **not run by the tests**: `review_gen.py` writes files of up to 2 GB. The same shapes
are built in memory by `../sandbox.rs` (2 GiB flate bomb as a 2 MB file, declared 2e9 x 2e9 image,
20000 x 20000 RGB image of 1.2 GB decoded, million pages), `../poison.rs` (self-using tiling
pattern, 725 bytes) and `../hostile.rs` (nesting). The shape `xref_huge.pdf` (xref subsection
with 4e9 entries) is not reproduced in Rust; UNCERTAIN: it is only covered by the process limits.
