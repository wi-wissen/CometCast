Wie seid ihr verbunden?

Der Bildschirm hängt an

Gleiches WLAN: Dein Gerät und der Bildschirm reden direkt miteinander.

Alle Wege unten gehen.

Eine Ausnahme: Manche Firmen- und Schulnetze trennen Geräte auch im selben WLAN. Klappt gar nichts, lies bei „anderes WLAN vor Ort“ weiter.

Anderes WLAN: Die beiden Netze sind meist absichtlich getrennt.

Eingebaute Wege wie AirPlay, Cast oder Miracast gehen hier nicht. Comet Cast findet den Bildschirm trotzdem über seinen Code. Ob das Bild durchkommt, hängt von eurem Netz ab:

  • Zuverlässig: Eure Organisation betreibt einen eigenen Comet-Cast-Server. Dann läuft das Bild über diesen Server und bleibt im Haus. Eure IT richtet ihn einmal ein, du musst nichts einstellen.
  • Ohne eigenen Server klappt es nur, wenn euer Netz die Verbindung durchlässt. Kommt keine zustande, verbinde dich mit dem WLAN des Bildschirms, wenn du darfst.

Für eure IT: wann ihr einen eigenen Server braucht

Ganz woanders: über das Internet.

Eingebaute Wege gehen hier nicht. Comet Cast verbindet die beiden über das Internet. Das klappt meistens. Strenge Netze, etwa bei manchen Firmen oder Mobilfunkanbietern, brauchen den eigenen Server der Organisation.

Für eure IT: wann ihr einen eigenen Server braucht

Eingebaute Wege (AirPlay, Cast, Miracast) gehen nur, wenn dein Gerät und der Bildschirm im selben WLAN sind. Comet Cast verbindet auch über Netze hinweg; zwischen einem Gäste-WLAN und einem internen Netz klappt das zuverlässig nur mit dem eigenen Server eurer Organisation.

Dann sind es drei Schritte

  1. Der Bildschirm zeigt einen Code

    Dazu einen QR-Code und die Adresse zum Öffnen.

  2. Du gibst ihn ein oder scannst ihn

    Oder du tippst in der App auf den Bildschirm in der Liste in der Nähe.

  3. Du präsentierst

    Deinen Bildschirm, ein PDF, ein Foto oder einen Link. Brauchst du kurz Zeit? Drück Pause, und der Raum sieht das letzte Bild.
