Where your data goes

The picture goes straight from your device to the screen. A small server only helps the two find each other.

What the relay sees and stores

The relay is a small server that matches a device and a screen by their room code and passes along the messages they need to set up the connection. It sees the room code, the name of the screen and your network address (to slow down abuse). It keeps rooms in memory only and stores nothing on disk. Pictures, files and links never go through the public relay.

If the direct way is blocked

Some networks do not let two devices talk directly. An organisation can then run its own server with a TURN relay: the picture travels through that machine, inside the organisation, and not through the public relay. Host it yourself explains how.

Screens nearby and signed announcements

Screens in your network announce themselves so that the app can list them. Every announcement is signed with a key that belongs to the screen, so another device on the network cannot pretend to be it, remove it from your list or change what it says. When a device joins with a name that another device used before, the screen shows a neutral note.

The connection check code

After two devices connect, both show the same short code. If the codes match, nobody sat in between. You do not have to compare them, but you can.
