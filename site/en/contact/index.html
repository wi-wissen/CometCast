Contact and security

Bugs and ideas

Please open an issue on GitHub: github.com/wi-wissen/CometCast/issues.

Vulnerabilities

Please do not open a public issue. Use GitHub's private reporting: open the Security tab of the repository and choose Report a vulnerability. If that is not shown, open an issue that says only that you need a private channel, without details. There are no fixed response times yet. The full policy: SECURITY.md.
