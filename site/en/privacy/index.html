The relay server

The relay server (cometcast-server) mediates between sender and receiver: room codes and connection offers (signalling). It stores no images, files or media and does not forward them. Rooms live in memory only. To protect itself it sees and counts the client address (for limits and temporary bans, also in memory only). With a TURN relay (coturn, internal server only) the media stream passes through that machine when needed.

A public server relay.cometcast.de is planned but does not exist yet. Operations files and the guide for that host live in the repository CometCast-Relay.

Self-hosting

Your own server is a Docker image (the web app is bundled, so one container is enough, even without internet) or a single program. There are two modes: open (public, mediation only, ALTCHA puzzle to create a room) and internal (for an organisation's own devices, with TURN credentials).
