Downloads and status

Comet Cast is a beta (0.1). This page says what works and what does not.

Downloads

Latest release on GitHub ReleasesOpen web app

When this page was written (2026-11-07) no release is published on GitHub yet. The link then leads to an empty or missing page. There are files only once a release appears there. To try it now, build from source (see the README).

The web app at /app/ is a placeholder: UNCERTAIN whether and when it is there. It consists of static files and can be hosted on this site; it then talks to a relay server over wss. The connection to relay.cometcast.de is not finished, and that server does not exist yet.

Status table (as of 2026-11-07)

Source: docs/architecture.md and the README. Nothing beyond that is claimed. What is not in the table is a plan.

Browser: sender and receiver (screen over WebRTC, room code, toolbar, images, links, PDF)works (limited)Works, but checked only on one machine / a local network (PDF and media links only with Chromium on Linux). Screen sharing needs HTTPS and a desktop browser; mobile is unchecked.
Signalling server (cometcast-server)partlyBuilt and tested. First real run on one Linux machine: Docker image, Compose, WSS, coturn with TURN credentials. Not verified: two real devices, NAT, TURN over TLS, IPv6, a real certificate, load, arm64.

Windows and macOS appnot working yetUntested. Capture not built there.
