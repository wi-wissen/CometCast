Host it yourself

Your own server keeps everything inside your organisation: room codes, the web app and, if you want, the picture itself.

One container is enough

The server is a Docker image with the web app inside, so one container works even without internet. It is also a single program you can run directly. There are two modes: open (public, only helps devices find each other, with a small puzzle to create a room) and internal (for the devices of an organisation, with TURN access so the picture stays inside your network).
