Downloads und Status

Comet Cast ist eine Beta (0.1). Diese Seite sagt, was funktioniert und was nicht.

Downloads

Neueste Version auf GitHub ReleasesWeb-App öffnen

Zum Zeitpunkt dieser Seite (2026-11-07) ist auf GitHub noch keine Version veröffentlicht. Der Link führt dann zu einer leeren oder fehlenden Seite. Dateien gibt es erst, wenn eine Version dort erscheint. Wer jetzt testen will, baut aus dem Quellcode (siehe README).

Die Web-App unter /app/ ist ein Platzhalter: UNCERTAIN, ob und wann sie dort liegt. Sie besteht aus statischen Dateien und kann auf dieser Seite gehostet werden; sie spricht dann per wss mit einem Relay-Server. Die Anbindung an relay.cometcast.de ist noch nicht fertig, und dieser Server existiert noch nicht.

Statustabelle (Stand 2026-11-07)

Quelle: docs/architecture.md und README. Nichts darüber hinaus ist behauptet. Was nicht in der Tabelle steht, ist ein Plan.

BereichStatusWas geprüft ist
Browser: Sender und Empfänger (Bildschirm über WebRTC, Raumcode, Werkzeugleiste, Bilder, Links, PDF)läuft (eingeschränkt)Funktioniert, aber nur auf einem Rechner / im lokalen Netz geprüft (PDF und Medienlinks nur mit Chromium auf Linux). Bildschirmfreigabe braucht HTTPS und einen Desktop-Browser; Mobil ist ungeprüft.
Signalisierungsserver (cometcast-server)teilweiseGebaut und getestet. Erster echter Lauf auf einer Linux-Maschine: Docker-Image, Compose, WSS, coturn mit TURN-Zugangsdaten. Nicht geprüft: zwei echte Geräte, NAT, TURN über TLS, IPv6, echtes Zertifikat, Last, arm64.
Öffentlicher Relay-Server relay.cometcast.deläuft noch nichtExistiert noch nicht.
Native Rust-Peers und Kommandozeile (cometcast-cli)teilweiseReden mit der Browser-App; Entwicklerwerkzeug. Linux-Bildschirmaufnahme (X11) mit H.264 vorhanden; Wayland, Windows, macOS nicht.
Flutter-Desktop-App (Linux)teilweiseNutzt den Rust-Kern, hat die Werkzeugleiste des Web-Empfängers. Nur Linux getestet. Bildschirmaufnahme und Videoanzeige in den nativen Apps sind noch nicht fertig.
Windows und macOS Appläuft noch nichtNicht getestet. Aufnahme dort nicht gebaut.
AirPlay empfangen (über UxPlay)teilweiseDer Steuerprozess läuft mit dem echten UxPlay unter Linux. Kein Test mit iPhone oder iPad; keine App-Integration; Windows fehlt.
Android und Android TV / Google TVläuft noch nichtEine Debug-APK baut. Auf keinem Gerät ausgeführt.
Apple TV (Empfänger)läuft noch nichtDer Quellcode liegt im Repository, funktioniert aber noch nicht.
Miracast empfangen (Windows 11)läuft noch nichtNur kompiliert, nie auf Windows ausgeführt.
Google Cast als Senderläuft noch nichtNur gegen einen eigenen Test-Empfänger auf demselben Rechner geprüft, nie gegen einen echten Chromecast.
AirPlay als Sender (ohne FairPlay)teilweiseSuche und Kopplung gegen UxPlay geprüft; alles andere nur gegen eigenen Test. Nichts auf einem Apple TV. Echte Bildschirmspiegelung ist wegen FairPlay bewusst nicht gebaut.
iOS-Broadcast-Erweiterungläuft noch nichtNicht begonnen.
STUN/TURN über echte Netzeläuft noch nichtNicht geprüft.
