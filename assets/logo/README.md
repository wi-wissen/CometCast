# Logo assets

The yellow "C" comet is the binding logo and app icon of Comet Cast.
Files are copied unchanged from the design hand-off. The SVGs are the
originals; derive all other sizes from them.

| File | Use |
| --- | --- |
| `cometcast-app-icon.svg`, `cometcast-app-icon-*.png` | Square app icon (store icons, desktop icons) |
| `cometcast-app-icon-round.svg` | Round app icon (Android adaptive/legacy round) |
| `cometcast-logo-dark.svg`, `cometcast-logo-dark-*.png` | Logo on dark backgrounds |
| `cometcast-logo-light.svg`, `cometcast-logo-light-*.png` | Logo on light backgrounds |
| `cometcast-logo-small.svg` | Favicon and 16-32 px uses |
| `cometcast-mono-black.svg` | Single-colour (print, stamps) |
